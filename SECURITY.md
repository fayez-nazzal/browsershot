# Security

## Supported versions

Only the latest release of `browsershot` gets security fixes.

## Reporting a vulnerability

Please do not open a public issue.

Report it privately through GitHub private vulnerability reporting.

1. Go to https://github.com/fayez-nazzal/browsershot/security/advisories/new
2. Describe the problem, the impact and the steps to reproduce it.
3. Include the version from `browsershot --version`.

You will get a first reply within seven days.

Please give us time to ship a fix before sharing the details publicly.
